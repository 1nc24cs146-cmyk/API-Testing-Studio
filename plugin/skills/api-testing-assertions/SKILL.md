# Skill: API Testing and Assertions

Status: Planned for v0.2 — NOT implemented in v0.1.2. Do not claim these features exist yet.

## Planned scope
- Status-code validation, response-time validation, JSON property validation, header validation, and schema validation.
- Test suites grouping assertions, test runs with pass/fail results, and test history.
- A controlled assertion engine — never execute arbitrary user JavaScript to evaluate a test.

## Until it ships
Use the response viewer in v0.1.2 to check status, time, size, headers, and JSON by eye, and use the history skill to re-run a request after a fix. Do not promise automated test reports in v0.1.2.
